## Install

To install paste this command

```bash
npx senn-ui@latest add <design-name>
```


## How it flows

1. pick a template you likeee
2. then run `npx senn-ui@latest add <design-name>` in your next.js project.
3. then copy the prompt or download the skill
4. then ask you ai to make it for youuu

```bash
npx senn-ui@latest skill modern-saas
```

You need Next.js 15 or newer, React 19 and Tailwind CSS v4. More about the commands in [cli/README.md](cli/README.md).
